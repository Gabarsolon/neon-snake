# Neon Snake

A neon snake game in a single HTML file. No build step, no dependencies.

**Play it:** https://gabarsolon.github.io/neon-snake/

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Steer | Arrow keys or WASD | Swipe |
| Start / pause | Space | Tap |
| Sound on/off | M | Speaker button |

Eat quickly to build a combo, up to ×9. Gold stars are worth extra but vanish if you're slow. The soundtrack is synthesised live with the Web Audio API and gets busier as your combo grows. Your best score is saved in the browser.

## Run locally

Open `index.html` in any modern browser.
